# Histoires où tu décides — UneVoix27

Des histoires interactives avec voix off et musique. À chaque étape, deux choix, et quatre fins par histoire.
Une nouvelle histoire sort régulièrement.

- `index.html` : la page d'accueil, avec les histoires déjà sorties.
- `commun/` : le logo UneVoix27, le logo de l'église et la musique de fond.
- `<histoire>/` : une histoire et ses voix.
